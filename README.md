# ![Flick Logo](public/fav.ico) Flick - OTT Streaming Platform (Frontend)

🚀 **Flick** is a modern OTT streaming platform built with **Next.js 14**, offering a seamless and immersive movie-watching experience. This repository contains the frontend code for Flick, designed for performance, responsiveness, and an intuitive UI.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **State Management:** React Context API
- **Authentication:** Cookies & JWT
- **Media Streaming:** Azure Cloud
- **Deployment:** Railway

## 🚀 Features
✅ Movie Search & Filtering  
✅ Movie Preview & Details  
✅ Authentication (Login/Register)  
✅ Secure API Calls with Token-Based Auth  
✅ Cloud Media Streaming  

## 📦 Installation & Setup

1. **Clone the repository:**
   ```sh
   git clone https://github.com/prashant-sehgal/flick.git
   cd flick-frontend
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Set up environment variables:** Create a `.env.local` file and add:
   ```env
   NODE_ENV=****
   NEXTAUTH_URL=****
   NEXTAUTH_SECRET=****
   GOOGLE_ID=****
   GOOGLE_SECRET=****
   DOMAIN=****
   NEXT_PUBLIC_API_URI=****
   NEXT_PUBLIC_MEDIA_URI=****
   ```

4. **Run the development server:**
   ```sh
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🚀 Deployment
Flick frontend is deployed on **Railway**. To deploy manually:
```sh
railway up
```
